  1. 앱을 열면 기기의 현재 시각과 현지 시간대에 맞춰 한글 시계가 표시됩니다.

3-1. 버전 1.2.0(빌드 8) 이상 — 선택에 따른 사용 분석

이 항목은 1.2.0(빌드 8)부터 적용됩니다. 1.0.0(3), 1.0.1(빌드 6), 1.1.0(빌드 7)에는 Firebase 사용 분석이 없습니다. 사용자가 이 버전에서 공유를 켠 이후의 정보만 분석하며, 이전 버전이나 공유를 켜기 전의 이용 이력은 소급 수집하지 않습니다.

사용 정보 공유는 기본적으로 꺼져 있습니다. 앱의 개인정보 안내에서 ‘사용 정보 공유’를 직접 켠 경우에만 Google의 Firebase Analytics(Google Analytics)를 시작합니다. 이 선택은 광고 SDK의 ATT 추적 권한과 별개이며, 공유하지 않아도 모든 시계 기능을 사용할 수 있습니다.

공유를 켜면 다음 정보가 Google에 전달되어 기능 개선과 사용 성과 분석에 사용됩니다.

  • 앱 실행·활성화 등 기본 이용 정보와 앱 설치 단위를 구분하는 가명 앱 인스턴스 식별자, 시계 세션 식별자
  • 시계 화면이 전면에서 활성화된 시간, 한 시계 세션의 누적 활성 시간 5분 달성 여부, 사용한 테마·화면 방향, 날짜·초·글자 크기·감광·애니메이션·효과음·화면 켜두기 설정 변경. 설정 패널·잠금·백그라운드 시간은 제외하며, 화면을 실제로 바라본 시간을 뜻하지 않습니다.
  • 앱이 조회에 성공했을 때 확인한 시계·일력 위젯의 설정 개수. 1.3.0부터 잠금화면 시계 위젯의 관측한 설정 개수도 포함합니다. 위젯의 실제 노출이나 시청 시간은 측정하지 않습니다.
  • 1.3.0부터 위젯 추가 안내를 연 기록과 허용된 위젯 링크 경로를 통해 앱을 연 기록. 앱에서 관측한 동작이며, 위젯의 실제 노출이나 설치 완료를 뜻하지 않습니다.
  • 기기 모델, 운영체제, 앱 버전, 언어 등 기본 환경 정보와 통신 IP 주소에서 추정하는 국가·지역 등 대략적인 위치. GPS나 정밀 위치는 수집하지 않습니다.

이 정보는 앱 인스턴스 식별자와 연결되므로 익명 정보라고 보장하지 않습니다. 이름·이메일·전화번호·계정 정보·자유 입력 내용·화면 캡처를 사용 분석 이벤트에 넣지 않으며, 화면 녹화나 크래시 수집 SDK도 사용하지 않습니다. 이 Firebase 구성은 광고 식별자(IDFA)를 수집할 수 없는 모듈을 사용하고 공급업체 식별자(IDFV) 수집도 끕니다. 광고 저장·광고 사용자 데이터·광고 개인 최적화는 허용하지 않습니다. 별도의 Meta·TikTok 광고 측정은 위의 ATT 안내에 따릅니다.

위젯 생존 신호 기능이 포함된 업데이트에서는, 사용 정보 공유를 켠 기기의 기존 홈 화면·스탠바이 시계와 일력 위젯이 갱신될 때 앱을 열지 않아도 UTC 날짜 기준 하루 최대 한 번 최근 작동 신호를 보냅니다. 1.3.0의 새 잠금화면 위젯 자체는 이 신호를 보내지 않습니다. 앱 인스턴스 식별자, UTC 날짜, 신호를 보낸 위젯 종류(시계 또는 일력)를 Supabase 중계 서버에서 처리한 뒤 Firebase Analytics로 전달합니다. 중복 방지를 위한 식별자는 서버에서 해시하여 저장합니다. 홈 화면과 스탠바이 위치, 실제 노출·시청 시간은 구분하거나 측정하지 않습니다. iOS의 실행 제한이나 네트워크 오류로 신호가 없을 수 있으며, 신호가 없다고 위젯이 삭제된 것은 아닙니다. 공유를 끄면 새 전송을 중단하지만 이미 전송 중인 요청이나 전달된 데이터는 취소되지 않습니다. 서버의 중복 방지 기록은 약 35일 보관 후 매일 예약 작업으로 정리하며, 중계 과정에는 Supabase 개인정보처리방침도 적용됩니다.

언제든 같은 ‘사용 정보 공유’ 설정을 끌 수 있습니다. 끄면 새 사용 분석 수집을 중단하고 기기의 Firebase 분석 데이터와 앱 인스턴스 식별자를 초기화합니다. 이미 전송된 정보나 전송 중인 요청이 자동 삭제되지는 않으며, 원격 삭제를 보장하지 않습니다. Google의 처리·보관에는 Google 개인정보처리방침과 Firebase 개인정보 및 보안 안내가 적용됩니다. 관련 요청은 위 지원 이메일로 보내주세요.

4. 처리 목적과 제공받는 곳

광고 성과 측정의 수신자는 Meta와 TikTok입니다. 기기 ID·제품 상호작용·대략적인 위치·기타 상황 정보는 이 앱의 광고·마케팅, 제3자 광고 서비스 및 분석에 사용되며, 다른 앱·웹사이트의 정보와 연결하는 광고 추적에 이용될 수 있습니다. 기기 ID는 측정 SDK의 동작에도 사용합니다. 성능·기타 진단 데이터는 분석과 앱 기능을 위해 사용하며 광고 추적 목적으로 사용하지 않습니다.

전송된 정보의 처리·보관·삭제에는 각 수신자의 정책이 적용됩니다. 자세한 내용은 Meta 개인정보처리방침과 TikTok for Business 개인정보처리방침, TikTok 비즈니스 제품 데이터 약관을 확인해 주세요. 정보 열람·삭제 등 개인정보 관련 요청은 위 지원 이메일이나 해당 업체의 개인정보 문의 경로로 보내실 수 있습니다.

5. 권한 변경·저장과 삭제

추적 권한은 아이폰 설정 → 개인정보 보호 및 보안 → 추적에서 변경할 수 있습니다. 추적 권한을 철회하면 앱의 새 광고 측정 이벤트를 중단합니다. 다만 SDK가 이미 전달받거나 저장한 정보와 철회 전에 전송이 시작된 요청은 이후에도 처리될 수 있으며, 이미 전송한 요청을 회수하거나 수신자 측 정보를 원격 삭제할 수 있다고 보장하지 않습니다. 앱 삭제나 권한 철회만으로 이미 전송된 정보가 자동 삭제되지는 않습니다.

시계 설정은 사용자가 앱을 이용하는 동안 기기에 유지됩니다. 앱을 기기에서 삭제하면 앱의 로컬 설정도 제거됩니다. 기기 백업과 복원은 사용자의 iOS 설정 및 Apple의 정책에 따릅니다.
